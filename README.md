## Локальный запуск

1. Клонировать репозиторий:
```bash
git clone https://github.com/rek655869/client-service.git
cd client-service
```

2. Создать в корне файл .env с содержимым:
```
POSTGRES_PASSWORD=123
DB_PASSWORD=456
```

3. Собрать образ:
```bash
docker compose up -d --build
```

4. Перейти по адресу [http://localhost:8080/swagger-ui/index.html](http://localhost:8080/swagger-ui/index.html)


## Задание
### Функциональные требования: 

Необходимо реализовать следующие REST-эндпоинты:
1. POST `/api/clients` (Создание записи о клиенте)

    Принимает Json с полями `fullName`, `gender`. По умолчанию клиент создается со статусом ACTIVE (активный пользователь)
2. GET `/api/clients` (Получение списка всех пользователей)

    Возвращает Json со списком всех клиентов (набор полей которые возвращаются по каждому клиенту, остается на твое усмотрение) 
3. GET `/api/clients/{id}` (Получение клиента по идентификатору)

    Возвращает информацию о пользователе (набор полей которые возвращаются по клиенту, остается на твое усмотрение), если он найдена. Если нет — возвращает HTTP 404 (Not Found).
4. PUT `/api/clients/{id}` (Обновление задачи)

    Принимает json с обновляемыми полями. Обновляет информацию о существующем клиенте. Если клиент не найден – возвращает 404
5. `DELETE /api/clients/{id}` (Удаление информации о клиенте)

    Жестко удаляет информацию о клиенте. Если клиент не найден – возвращает 404


### Технологический стек: 
1. Java(11,17,21)
2. Spring Boot
3. Maven
4. Hibernate (Spring Data JPA)
5. Реляционная БД (PostgreSQL).

```

-------------+-----------------------------+----------+----------------------------------+-------------------
 id          | bigint                      | not null | generated by default as identity | Идентификатор
 full_name   | text                        | not null |                                  | ФИО
 gender      | character(1)                |          |                                  | Пол
 status      | character varying(20)       |          |                                  | Статус
 create_dttm | timestamp(6) with time zone | not null |                                  | Дата создания
 modify_dttm | timestamp(6) with time zone | not null |                                  | Дата обновления
 ```
